# Media

Drop final images at these paths, then add each path to `images.json`
(e.g. `["Media/packages/home-5kwp.jpg", "Media/reviews/worawut.jpg"]`).
Until a path is listed, its frame shows the built-in line drawing (packages)
or the reviewer's initial (reviews), and nothing is requested from the server.

Packages (16:9 or 4:3, at least 1200px wide):
- Media/packages/home-5kwp.jpg
- Media/packages/home-hybrid-10kwp.jpg
- Media/packages/business-30kwp.jpg
- Media/packages/factory-100kwp.jpg
- Media/packages/factory-300kwp.jpg
- Media/packages/factory-1mwp.jpg

Reviewer portraits (square, at least 160px):
- Media/reviews/worawut.jpg
- Media/reviews/napatsorn.jpg
- Media/reviews/pichaya.jpg
- Media/reviews/surachet.jpg

With a package photo present, the photo shows by default and the drone clip
plays over it on hover.
